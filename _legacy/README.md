# Aussie AI Website Builder - MVP

澳洲 AI 智能建站平台简易版 MVP

## 功能特性

✅ **产品介绍页面**
- 清晰的价值主张和卖点展示
- 四大核心优势卡片

✅ **案例滚动展示**
- 5 个行业案例自动轮播
- 支持手动切换（左右箭头）
- 暂停/播放功能

✅ **AI 聊天机器人**
- 右下角悬浮窗口
- 支持关键词智能回复
- 快捷问题按钮
- 中英文对话

✅ **透明报价展示**
- 三档套餐对比
- 澳元计价（AUD $599 / $1,299 / $2,499+）

✅ **中英文切换**
- 一键切换界面语言
- 全站内容实时翻译

✅ **移动端优化**
- 响应式设计
- 手机端完美适配

## 使用方法

### 本地预览

1. 直接打开 `index.html` 文件即可在浏览器中查看
2. 或使用本地服务器（推荐）：

```bash
# Python 3
python -m http.server 8000

# 或使用 Live Server（VS Code 扩展）
```

3. 访问 `http://localhost:8000`

## 文件结构

```
aussie-ai-builder/
```

## 技术栈

- **前端**: 纯 HTML5 + CSS3 + Vanilla JavaScript
- **无依赖**: 不需要 Node.js、React 或其他框架
- **浏览器兼容**: Chrome, Safari, Firefox, Edge（最新两个版本）

## 功能说明

### 1. 案例轮播
- 自动播放（4秒间隔）
- 鼠标悬停暂停
- 支持左右箭头切换
- 圆点指示器点击跳转

### 2. AI 聊天机器人
简单的关键词匹配机器人，支持以下问题类型：

**英文关键词**:
- `price/cost` → 报价信息
- `how long/time` → 交付时间
- `technical/skill/code` → 技术要求
- `industry/business` → 适用行业
- `contact/email/phone` → 联系方式

**中文关键词**:
- `报价/价格/多少钱` → 报价信息
- `多久/时间` → 交付时间
- `技术/懂/会` → 技术要求
- `行业/生意` → 适用行业
- `联系/邮箱/电话` → 联系方式

### 3. 语言切换
点击右上角"中文/English"按钮即可切换全站语言。
